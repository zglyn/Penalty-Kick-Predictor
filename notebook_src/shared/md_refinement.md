### Refinement of a finished run (`RUN_MODE='refine'`, no video retraining)
Point `TRAINED_RUN_DIR` at a finished `nested_cv` run. The notebook reuses every saved model: it regenerates each fold's inner-validation predictions with the saved inner models (inference only), refits a class-weighted pose/motion CatBoost per stage (CPU, minutes), reselects each task's ensemble on **inner** predictions only (predeclared candidates; max inner accuracy, then lower cross-entropy, then fewer components), optionally fits a center-class offset on inner predictions, and applies these frozen choices to the saved outer predictions (exploratory comparison) and to the private clips (new `submission.csv`). It also writes Priority-0 audits: `label_mapping_audit.json`, `temporal_input_audit.csv`, `crop_geometry.csv`, `label_convention_samples/`. Everything goes to a new folder `<parent>__refine_<id>`; the parent run is never modified. Its `inference_manifest.json` replays the refined ensemble without reselecting anything.
